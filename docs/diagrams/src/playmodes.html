KamoteKeys — play modes (SMK-37)

Keyboard on top, the 16 pads below. Mode button again = back to Normal. Clip and Step Mode have their own diagrams. In all four modes the top octave (F to C, except C# D D# E) controls Live's selected track / clip: delete, finish, launch / stop, solo, mute, arm, quantize; hold top C for scene / track navigation.
