KNOBS · pages, ARP types, CHORD KEYS, Note Repeat, step automation

KamoteKeys · SMK-37 · macros and effects need the KamoteKeys Remote Script · blue = with SHIFT (top C) held

Knob pages

1 · Default: MACRO page (like Move): the 8 macros of the selected track's first rack; no rack = the first 8 controls of its first device. The screen shows the name and value.
2 · Hold SHIFT (top C) + knobs: MIX page: tempo and the selected track's effects
3 · PATCH page (tap PATCH): key, scale, brightness, then CHORD KEYS (E7) and its voicing (E6)
4 · ARP page (hold ARP): TYPE; for strums E2 = speed and E3 = by TIME or BARS

ARP types (E1 on the ARP page; ARP button = on / off)

ARPEGGIOnotes one after another (direction, division, gate, swing, octaves) STRUM ↑chords strummed low → high; E3 TIME: 8–500 ms between notes, or BARS: 1/32 … 4 bars (follows the tempo); E2 = speed STRUM ↓high → low STRUM ↕alternates down / up on every chord, like a guitar CHORD REPEATthe whole chord re-struck on the beat (division, gate, swing): stabs and pulses HUMANIZEchord notes a few ms apart at random, velocities varied a little

Buttons

NOTE REPEATNote Repeat: hold it and press pads (or keys): they repeat at the rate; harder = louder. While held, E1 = rate (1/4 … 1/32T). Tap = Sustain. SEQ PLAY = AUTOStep automation (Step Mode): turn AUTO on (lit), hold a step and turn knobs: the macros are written for that step only (Move's parameter locks). AUTO off: hold step + E1 / E2 / E3 = velocity / length / repeats. AUTO on + DELETE + step: clear that step's automation. PATCHtap: PATCH page (above); + PARA: metronome Every knobshows what it changes on the screen as you turn it · Diagnostics (hold BT): E3 = pad sensitivity

CHORD KEYS (PATCH E7) · every key plays a chord on its note

  • Same shape on every key: m9 (A → A C E G B), maj9, 9, m11, maj7#11, 9sus4, 6/9, m6/9, add9, madd9, quartal (stacked 4ths), power.
  • From the scale: SCALE 7TH · SCALE 9TH (C major: Am9 on A, Cmaj9 on C, G9 on G) · SCALE 11TH · SCALE SUS2.
  • Voicing (E6): CLOSE · SPREAD (root an octave down) · DROP 2 (2nd note from the top an octave down).
  • Chord pads held still win; LOCK, ARP and strum work with it; OFF = single notes.
