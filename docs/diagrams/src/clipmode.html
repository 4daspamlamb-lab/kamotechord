Keyboard

With SHIFT held (top C) · moving around

  • Hold top C (SHIFT) and press:
  • G# / A# = scene ▲ / ▼ · F# = launch the selected scene
  • F / G = track ◀ / ▶ (keep holding: one more every 0.5 s); the 8 tracks shown follow
  • A = duplicate the selected clip into the next empty slot below · B = double its loop
  • E = fixed record length OFF → 1 → 2 → 4 → 8 bars
  • MOVE a clip: hold the low E instead of SHIFT and press G# / A# = move the selected clip one scene up / down.

Pads = clip slots (top row = scene 1, bottom = scene 2; tracks 1–8) · press = SELECT (default) or PLAY

Moves

  • Pad press: SELECT (slot + arm its track; KNOB BANK records there). PLAY (F#): hold + clips = launch / stop them; or tap F# and the next clip pressed is launched.
  • Hold MOVE (low E) + top G# / A#: move Live's selected clip one scene up / down (it stays selected).
  • Live strip + SHIFT (hold top C): F / G = previous / next track (hold: one more every 0.5 s), G# / A# = scene up / down, F# = launch the selected scene, A = duplicate clip, B = double loop, E = fixed record length. Without SHIFT: F quantize, F# play / stop, G arm, G# finish & next, A mute, A# delete, B solo.
  • Hold OVERDUB (lowest C) + pad: overdub into that clip (an empty slot: arm and record a new clip); tapping the pad again ends the overdub.
  • COPY (C#) tap or hold, then a clip · PASTE (D#) tap = next pad, hold = several pads.
  • Hold DELETE (A#) + pad: delete that clip.
  • Hold STOP (G#) + clips: stop them; tap G#: stop the selected clip.
  • D: SCENE ARRANGE on / off. The two rows are two scenes; tap a pad to turn that track on (green) or off (dim orange) in that scene (dark = the track has no clip). Each track keeps one clip: a scene plays the track's clip from that scene, or the nearest one above / below. Saved in the Live set.
  • SHIFT + F#: launch the selected scene: with an arrangement it plays exactly the chosen tracks' clips and stops the others (edit a clip once, every scene hears it). SHIFT + G# / A#: scene up / down.
  • Screen: clip state, selected track number + name (big), scene, the 8 tracks shown, SELECT / PLAY, clipboard (COPIED T3 S2); the pad map shows track numbers and names.
  • Mix the selected track: Fader 2 volume, Fader 3 Macro 1 (or Send A), E4–E7 filter / delay / reverb / sustain.
  • Hold CHORD from any mode: Clip Mode while held (launch, select, record), back to where you were on release. From Clip Mode press SEQ REC to step-sequence the selected slot.
