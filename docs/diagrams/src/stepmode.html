SEQ REC · Step Mode (step sequencer)

KamoteKeys · SMK-37 · press SEQ REC to enter / leave · needs the KamoteKeys Remote Script · edits Live's selected track + clip slot

Buttons

SEQ REC · Step Mode on/off (lit) · leaving returns to the mode you came from
PARA · play the clip (making it) · stop like the space bar
SEQ PLAY · AUTO (step automation)
CHORD tap · Clip Mode · hold: Clip Mode while held
top G# · finish clip, next track
GLOBE · light show
OCT −/+ · key zone octave (per track)
SEQ · drum keys ↔ scale keys (per track)
◀ / ▶ · page left / right

Keyboard

With SHIFT held (top C) · moving around

  • Hold top C (SHIFT) and press:
  • G# / A# = scene ▲ / ▼ · F# = launch the selected scene
  • F / G = track ◀ / ▶ (keep holding: one more every 0.5 s); the 8 tracks shown follow
  • A = duplicate the selected clip into the next empty slot below · B = double its loop
  • E = fixed record length OFF → 1 → 2 → 4 → 8 bars

Pads = 16 steps of the shown page (1 bar at 1/16)

Pad colours

note of the selected sound (brighter = louder)
inside a tied (long) note
step repeated 2× / 3×
other sounds on this step: 1 / 2 / 3+ (clear lilac, brighter = more)
empty step
playhead on a note (white on an empty step)
step held
past the end of the clip (off)
LENGTH / BARS held: bar in clip / shown / playing

Moves

  • No clip until the first step: an empty slot shows an empty 1-bar pattern; the first step you tap makes the clip (a deleted clip is not made again).
  • Tap a pad: note on/off for the selected sound.
  • Key zone key: plays the sound and selects it. OCT −/+ moves the zone, SEQ = scale keys (melodic tracks). Remembered per track.
  • Hold a step + a later step: one long (tied) note.
  • AUTO (SEQ PLAY, lit) + hold a step + turn knobs: that step's macros are written as clip automation (Move's parameter locks); AUTO + DELETE + step clears it.
  • AUTO off: hold a step + turn E1 / E2 / E3: its velocity / length / repeats (1× 2× 3×). New steps take the pad's velocity (Fader 1 above 10 % fixes it); E2 with no step held = length of new steps.
  • Hold NOTE LENGTH (low C) + pad n: new steps are n sixteenths long; steps held at the same time get that length.
  • Hold LENGTH + pad n: clip = n bars; growing it repeats the pattern into the new bars.
  • BARS (A) tap: bar view; tap a bar to show it. Hold DELETE + tap a bar: delete it (later bars move up); hold the bar pad 3 s: only clear it.
  • Chords: lock a chord on the main screen; with SEQ (scale keys) a key picks the chord, a pad writes it.
  • COPY tap/hold, then a step pad (all sounds in it), a key (that sound on the page) or, in the BARS view, a bar. PASTE tap = next target, hold = several. Screen shows what is copied.
  • DELETE (A#) tap: selected sound on this page. Hold + step: every note in it · + bar (BARS view): delete the bar (hold 3 s = clear) · + key: that sound in the whole clip.
  • Hold DRUM (B): pads = Drum Mode pads (same order and colours as FX); tap one to play it and select it.
  • Screen: BAR 2/4 while the clip plays. An existing clip's notes show at once; an empty clip Step Mode made is removed when you leave or move to another track / scene.
  • DOUBLE (F): the clip twice as long, everything copied.
  • The track is armed automatically while Step Mode is on. PARA plays the clip (making it if needed); while Live plays it stops, like the space bar. Leaving Step Mode returns to where you came from (e.g. Clip Mode).
